Before the curriculum

How to get the best out of me

Six things that change the quality of what you get back more than any prompt ever will. They're true of Freebuff, Claude Code, Codex, or whatever you're using next month.

sight

I can only see what you give me

Files you add to a chat, folders in a project, text you paste. I can't see your computer, your inbox or last week's conversation. If it matters, put it in front of me.

surface

Chat for thinking, Code for doing

Chat is for drafting, deciding and explaining. Code mode is for real files, running things, building and long jobs. Most disappointment comes from using one where you needed the other.

setup

Point me at the work

One folder. A two-line note saying what the project is and what good looks like. That single file saves more back-and-forth than any clever instruction.

feedback

Correct precisely, don't restart

Quote the exact line that's wrong and say what you wanted instead. "That paragraph repeats the intro" beats "try again" every single time.

verification

Ask me to prove it

"What did you change, what did you not check, and what could break?" is the most useful sentence you can send an agent. Then check the one thing a reader would test.

hard limit

Never paste secrets

Passwords, API keys, client data you don't have permission to share, anything medical or financial about a real person. Assume anything pasted could be stored.

Draw calls, not polygon count

        
Each separate object is a draw call. A hundred small meshes cost more than one detailed one. That's why the particles are a single object.

      

      

        
Easing is the whole trick

        
Linear motion reads as cheap. Multiplying by a small lerp factor each frame — rather than snapping — is what makes movement feel expensive.

      

      

        
Cap the pixel ratio

        
Retina screens can quadruple the pixels you're shading. Capping at 2 is the single biggest free performance win on a 3D page.

      

      

        
Always plan the fallback

        
Some devices have no WebGL, and some people turn animation off because it makes them ill. A static frame that still looks finished is part of the design.

        good at, roughly what it costs, and when reaching for it beats just asking an agent.
      

    


    

      

        

          
Agents that work in your files

          
Read a project, edit it, run things. The most capable category for multi-step work.

        

        
    
          
  • Claude Code most used
    Deep multi-file work from the terminal, plus IDE, desktop and web. Plan mode, subagents, hooks, MCP, scheduled routines.
    $20 Pro · $100 Max · $200 Ultra
    • 
          
  • OpenAI Codex
    Open-source CLI plus cloud tasks that run in the background and come back as a pull request.
    ChatGPT Plus $20 → Pro $500
    • 
          
  • Cursor
    Editor-first: best when you want to watch and approve every diff inline.
    Free · $8 · $30 · $200
    • 
          
  • GitHub Copilot
    The safe team pick. Lives on GitHub, has a cloud agent, generous free tier.
    Free · $10 · $39 · $100
    • 
          
  • Google Antigravity
    Google's agent surface. Free with weekly limits, sensible if you already pay for Gemini.
    Free tier · Google AI plans
    • 
          
  • Cline · OpenCode · Aider
    Open source, bring-your-own-key. Cheap, inspectable, no subscription lock-in.
